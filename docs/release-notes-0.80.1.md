# Sceneform 0.80.1 (beta)

A small visual update to the [0.80.0 beta](https://github.com/sceneform/sceneform/releases/tag/v0.80.0).

## Changed

- **New icons:** every icon in the app now comes from [Tabler Icons](https://tabler.io/icons) (MIT), at one consistent stroke width. The Sceneform mark is unchanged.
- **Window controls** (minimise, maximise, restore, close) use the same set and are a little larger and crisper.
- Settings › More › About now credits Tabler Icons.

No changes to the project format, the editor or exports; 0.80.0 projects open as before.

> **Beta:** back up your projects. Every save also keeps a `.bak` next to the `.sfp`, and File → Local history keeps snapshots.
